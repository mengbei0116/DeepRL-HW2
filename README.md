# 強化學習HW2報告：Q-learning 與 SARSA 之懸崖漫步 (Cliff Walking) 比較分析

## 1. 實驗目的

本實驗旨在透過經典的「懸崖漫步（Cliff Walking）」問題，實作並比較兩種基礎強化學習演算法：**Q-learning** 與 **SARSA**。透過觀察兩者在相同環境下的學習曲線、最終收斂策略以及路徑選擇，深入理解「同策略 (On-policy)」與「異策略 (Off-policy)」在處理帶有風險的環境時的行為差異。

## 2. 環境設置與問題設定

* **環境架構**：4x12 的網格世界。
* **起點與終點**：起點位於左下角 $(3, 0)$，終點位於右下角 $(3, 11)$。
* **懸崖區域**：起點與終點之間的最下排格點 $(3, 1 \sim 10)$ 定義為懸崖。
* **動作空間**：上下左右移動一步（若撞牆則留在原位）。
* **獎勵機制**：
  * 每移動一步：-1 分。
  * 掉入懸崖：-100 分，且立即回到起點重新開始。
  * 到達終點：結束該回合。
* **實驗超參數**：
  * $\epsilon$-greedy 探索率：0.1
  * 學習率 ($\alpha$)：0.1
  * 折扣因子 ($\gamma$)：0.9
  * 訓練設定：共跑 50 次獨立實驗，每次訓練 $500$ 回合，結果取平均值。

---

## 3. 演算法理論差異比較

本實驗的核心在於比較以下兩種時間差分 (Temporal Difference, TD) 控制方法：

### Q-learning (Off-policy)

其更新公式如下：
$$Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s, a)]$$

* **特點**：在更新 Q 值時，它假設下一階段會採取「最佳行動」（max Q），不論實際採取的行動為何。這使它能學到理論上的**最優策略（Optimal Policy）**，但更新過程與實際執行的策略（帶有 $\epsilon$ 探索）是脫鉤的。

### SARSA (On-policy)

其更新公式如下：
$$Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma Q(s', a') - Q(s, a)]$$

* **特點**：更新時基於「實際採取的下一行動」（s, a, r, s', a'）。這意味著 SARSA 會將探索過程中的隨機風險納入考量。如果環境中存在高風險區域，SARSA 會傾向於學習更為**保守/安全的策略**。

## 5. 結果討論與分析

### 5.1 學習表現與收斂速度

根據 **Reward sum** 曲線圖：

* **收斂速度**：Q-learning 與 SARSA 在前 100 回合皆展現了快速的進步。然而，SARSA 的曲線在收斂後明顯高於 Q-learning。
* **累積獎勵**：SARSA 最終穩定在約 $-25$ 左右，而 Q-learning 則在 $-50$ 附近劇烈震盪。這是因為 Q-learning 選擇的路徑緊貼懸崖，在 $\epsilon=0.1$ 的探索下，極易因隨機動作掉入懸崖獲取 $-100$ 的處罰，導致平均得分降低。

### 5.2 策略行為分析

根據 **Grid Policy** 網格圖：

* **Q-learning (冒險型)**：學習到了最短路徑（即緊貼懸崖的最底排上方）。雖然這條路徑理論上步數最少，但在執行時容錯率極低。
* **SARSA (保守型)**：學習到了一條「繞遠路」的策略（向上繞行）。雖然步數較多，但即使發生 $\epsilon$ 隨機探索，掉入懸崖的機率也微乎其微。這證明了 SARSA 會為了安全而犧牲部分效率。

### 5.3 穩定性分析

* **波動程度**：Q-learning 的學習曲線波動較大，這反映了其「Off-policy」的特性——它學習的是最優值，但執行的是探索值，兩者間的矛盾在懸崖環境中被放大。
* **探索的影響**：本實驗設定 $\epsilon = 0.1$。對於 SARSA 而言，它在訓練中就意識到隨機探索會導致掉落，因此修正了 Q 值；而 Q-learning 則「無視」了這種因探索帶來的風險，堅持追求理論上的最短距離。

---

## 6. 總結

本實驗成功驗證了 Q-learning 與 SARSA 的本質區別：

1. **收斂較快者**：就「尋找最優路徑」而言，**Q-learning** 能更直接地鎖定最短路徑；但就「平均獎勵收斂」而言，**SARSA** 能更快達到穩定且較高的回報。
2. **穩定性**：**SARSA** 明顯優於 Q-learning，其路徑具有較高的容錯能力。
3. **情境選擇建議**：
    * **選擇 Q-learning**：若實驗環境是在模擬器中（沒有實際損壞成本），且目標是尋找理論上的極限最短路徑（Optimal Path）。
    * **選擇 SARSA**：若是在現實物理環境中訓練（如無人機或機器人），掉落或碰撞具有真實的成本損失，則應選擇更為保守且穩健的 SARSA。
